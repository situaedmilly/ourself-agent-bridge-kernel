# SELFGRAPH REALISELF Instance Requirements

## Constitutional purpose

This contract answers a bounded engineering question:

> **What instances must exist and be witnessed before a bounded OURSELF reality target may be described as runtime-realized?**

It does **not** claim that a numeric quantity of software objects creates metaphysical reality.

For a fully represented bounded target, the minimum jurisdictional set is **17 graph instances, one for each constitutional SELFGRAPH jurisdiction**.

The count is deliberately not the whole proof.

### Minimum set

1. CORE
2. IDENTITY
3. REALITY
4. FILE
5. RUNTIME
6. NETWORK
7. CAPABILITY
8. AUTHORITY
9. COGNITION
10. AGENTBRIDGE
11. SELFCOMM
12. ACTION
13. ALCHEMY
14. STATE_LINEAGE
15. EVENT
16. EVIDENCE
17. LIFECYCLE

Each must reach a witnessed standing before the bounded target can pass the minimum jurisdiction-instance gate.

### What is not counted as an eighteenth graph

ADMISSION is represented as a typed cross-graph relation.

The realization path is:

`CAPABILITY + AUTHORITY + CONTEXT + TARGET + CONSTRAINTS -> ADMITTED_AS -> ACTION`

Admission therefore requires relation evidence, not an `ADMISSION` graph.

### Reality-realization gate

The contract treats realization as a bounded evidence state:

`DECLARED -> REGISTERED -> PERSISTED -> INITIALIZED -> RUNNING -> WITNESSED -> ADMITTED -> ACTUATED -> EFFECTED -> CUSTODIED`

A graph instance can stop at a lower standing without pretending that a later standing exists.

Cross-graph relations, events, evidence, lineage records, receipts, and external-state witnesses are not capped at 17. They are target-dependent and can be unbounded.

## Codex execution intent

The next local execution should:

1. locate the current control-plane repository,
2. install/verify this contract,
3. generate the 17 minimum graph-instance records,
4. generate typed cross-graph relation witnesses,
5. run the validator,
6. emit a machine-readable receipt,
7. refuse any REALIZED standing if a required witness is absent.

No actuation authority is implied by this contract.
